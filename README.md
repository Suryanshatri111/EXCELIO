Excel Analytics Dashboard

The Excel Analytics Dashboard is a powerful web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) that allows users to upload, visualize, and analyze Excel data through interactive charts, tables, and insights.

Features

Excel File Upload: Easily upload .xlsx or .csv files for analysis.

Dynamic Data Parsing: Converts Excel sheets into usable JSON format for visualization.

Interactive Dashboards: Visualize data through customizable charts (bar, line, pie, etc.).

Data Filtering & Sorting: Analyze data with real-time filtering and sorting capabilities.

Performance Insights: Get summaries and insights from your raw data.

Secure File Storage: Uploaded files are securely stored and processed on the backend.

Responsive Design: Fully optimized for desktop and mobile devices.


Tech Stack

Frontend: React.js, Tailwind CSS, Recharts

Backend: Node.js, Express.js

Database: MongoDB

File Handling: Multer for file uploads, SheetJS for Excel parsing
